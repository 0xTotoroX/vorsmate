# 无人值守授权

无人值守授权用于在用户主动开启的时间段内，以事件驱动方式监测并尝试处理本机出现的系统管理员授权弹窗，适用于短时离开或连续执行本地脚本、安装与维护任务的场景。

## 核心规则

- **默认关闭与重启复位。** 首次启用模块、应用启动或重启后均默认关闭，不自动延续上次开启状态。停用「无人值守授权」模块或退出应用时，立即停止本次会话与监听。
- **监听范围。** 开启期间监测可识别的系统管理员授权请求。开启前需先配置本机管理员密码，并授予 Vorsmate macOS 辅助功能权限。
- **密码本机加密保存。** 录入密码时先经本机 OpenDirectory 核验当前账户口令，通过后写入本机钥匙串（`kSecClassGenericPassword`，服务名 `app.vorsmate.mac.unattended-auth`），明确配置为本地非同步（`kSecAttrSynchronizable = false`、`kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`）。密码不上云、不通过 iCloud 同步，绝不写入日志、剪贴板、`UserDefaults`、`settings.json` 或活动记录 JSON；监测弹窗时也不读取弹窗密码框内容。
- **更换与删除密码。** 详情页可随时更换密码（校验通过后立即生效）或删除密码。删除密码会立即关闭正在运行的无人值守授权，且在重新录入前无法再次开启。

## 可选截止时间与状态展示

开启时可不设截止时间，也可选择预设时长（15 分钟、30 分钟、1 小时、2 小时或自定义分钟）或指定晚于当前时刻的具体时间：

| 状态 | 菜单栏显示 | 完整状态文案（悬停 / 详情） | 总览状态 / 右侧值 |
| --- | --- | --- | --- |
| 关闭（已配置密码） | 原有样式，不额外显示 | 已关闭 | 已关闭 / 未开启 |
| 关闭（未配置密码） | 原有样式，不额外显示 | 已关闭 | 未配置密码 / 未开启 |
| 关闭（密码失效） | 原有样式，不额外显示 | 已关闭 | 密码已失效 / 需更新 |
| 开启 · 不设截止 | `无人值守` | `无人值守授权已开启 · 手动关闭` | `已开启 · 手动关闭` / `运行中` |
| 开启 · 已设截止 | `无人值守 · 剩余 <时长>` | `无人值守授权已开启 · 至 <时刻>（剩余 <时长>）` | `已开启 · 至 <时刻>` / `剩余 <时长>` |

- **未设截止时间时，所有位置均不显示到期时刻或剩余时长。**
- 到期时刻按当日 `HH:mm`、次日 `明日 HH:mm`、跨多日 `M月d日 HH:mm` 展示；剩余时长使用等宽数字。
- 开启期间即使面板收起，菜单栏仍持续显示开启状态。左键照常开关面板，开启期间右键菜单栏图标可查看当前状态并一键「关闭无人值守授权」；总览摘要行与详情页同样提供一键关闭。关闭面板不停止已开启会话；到期自动关闭或密码失效提示在总览收起态保持可见。

## 锁屏状态保持与自动停止

- **锁屏不改变开关。** 已开启的无人值守授权在锁屏后保持开启状态，不因锁屏自动关闭，解锁后也不要求重新开启。
- **截止时间照常生效。** 截止时间按系统墙钟核对：锁屏期间尚未到期的，解锁后保持开启并更新剩余时长；锁屏期间已到达截止时间的，自动关闭并记录为「到达截止时间」，解锁后如实回显已关闭状态与提醒。
- **解锁复核与密码失效自动停止。** 解锁后重新核对辅助功能权限与已保存密码。无论在开启前、解锁复核、弹窗触发前，还是弹窗返回密码被拒且二次核验失效时，一旦确认密码已失效，立即自动关闭模式、标记密码失效并提醒用户更新密码，不循环重试错误密码。
- **手动停止与在途保护。** 手动关闭立即停止监听并取消尚未提交的在途处理；后续弹窗不再介入，已获批操作保留记录，未完成的弹窗交回本人确认。
- **锁屏保持不影响重启规则。** 应用退出或重启后仍恢复默认关闭。

## 弹窗处理边界与活动记录

除常规系统管理员授权弹窗（`SecurityAgent`、`CoreServicesUIAgent`、`coreautha` 等）外，详情页内「自动批准选项」可按类别配置并持久化到 `Preferences`（version 1，默认全部开启）：

- **隐私与安全**：系统设置「隐私与安全」内嵌权限修改弹层（`com.apple.settings.PrivacySecurity.extension` / `com.apple.systempreferences`）。
- **软件权限许可**：应用申请访问提醒事项、日历、通讯录、照片、文件夹等隐私权限时弹出的无密码“不允许 / 允许”系统许可弹窗（仅处理经 `anchor apple` 验签的 `com.apple.UserNotificationCenter`、`com.apple.tcc.AuthorizationPromptService` 或系统代理窗口；必须同时具备显式允许按钮与拒绝/取消按钮且文本匹配权限请求句式，排除 Gatekeeper / 恶意软件拦截弹窗，绝不回退 `kAXDefaultButtonAttribute` 也绝不模拟移动或点击系统鼠标，仅通过 `AXPress` 触发并做关闭复核）。
- **密码与通行密钥**：浏览器或应用内嵌的通行密钥、Apple 密码与账号授权弹层（仅在输入或切换控件经 `anchor apple` 验证属于 `AuthenticationServices.Helper`、`AuthenticationServicesAgent`、`LocalAuthenticationRemoteService` 或 `AKAuthorizationRemoteViewService` 等 Apple 授权服务时才提交，绝不向普通应用或浏览器自身输入框写入密码）。
- **已弹出的请求**：开启无人值守授权前屏幕上已出现的授权弹窗。

上述选项开启时进入自动处理与关闭复核流程；若对应选项被关闭，或遇到系统安全策略拦截导致弹窗未关闭、无密码输入框、无安全匹配的许可按钮、触控 ID 界面切换失败、钥匙串读取失败等情况，一律保留由本人确认并如实记录原因（如「隐私与安全请求由本人确认」「软件权限许可请求由本人确认」「密码与通行密钥请求由本人确认」「开启前已存在的请求由本人确认」或「自动批准受阻，保留本人确认」），且不对同一滞留窗口循环重试，**绝不伪装为已批准**。

关闭状态下完全不介入系统弹窗。开启状态下仅在确认原弹窗确实关闭后，才记录为「已自动批准」。

活动记录保存在本机应用支持目录 `~/Library/Application Support/Vorsmate/unattended-auth-history.json`（POSIX 权限 `0o600`，与配置共用同目录写锁与原子写入，最多保留最近 30 次会话；预览模式仅内存保存），支持在详情页查看和清空。记录绝不包含真实密码，写入前会对提示摘要和来源剔除任何与当前保存密码匹配的文本。

| 层级 | 字段 | 说明 |
| --- | --- | --- |
| 会话 | `id`、`startedAt`、`endedAt`、`deadline`、`stopReason`、`events` | 起止时间、可选截止时间、停止原因（手动关闭 / 到达截止时间 / 密码失效 / 密码已删除 / 模块已停用 / 应用退出）与该会话下的弹窗记录 |
| 弹窗事件 | `id`、`timestamp`、`source`、`summary`、`outcome`、`detail` | 出现时间、请求来源、脱敏且限长 140 字符的公开提示摘要、处理结果（已自动批准 / 自动批准受阻，保留本人确认 / 保留本人确认 / 密码失效，已自动关闭）与具体说明 |

## 验证范围与已知边界

以下三类口径严格区分，通过其中一项不代表其他项已完成实机验收：

### 已验证的实机能力与监测样本

- **「录屏与系统录音」已有弹窗（macOS 27.3）：** 系统设置的真实密码弹窗保持打开，以隔离的只读驱动验收开启流程。开启时记录一条「隐私与安全 · 保留本人确认」，重复补查没有增加记录，未提交密码，系统弹窗仍等待本人确认。
- **隔离非同步钥匙串全链路实测（macOS 27.3）：** 使用隔离服务名验证了 `kSecAttrSynchronizable = false` 与 `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly` 的写入（`SecItemAdd`）、属性与数据回读（`SecItemCopyMatching`）、更新（`SecItemUpdate`）及删除后复核（`SecItemDelete` → `errSecItemNotFound`）全链路通过。
- **OpenDirectory 本地口令核验实测（macOS 27.3）：** 对当前本地账户传入错误口令时，`ODRecord.verifyPassword` 实测返回 `ODFrameworkErrorDomain` / `kODErrorCredentialsInvalid (5000)`，与驱动判定 `.invalid` 一致。
- **实时管理员弹窗宿主命中与系统文案对齐（macOS 27.3）：** 实时触发 `osascript` 管理员授权弹窗时，`SecurityAgent`（`com.apple.SecurityAgent`）宿主识别实测命中；并对照本机系统 Bundle `Info.plist` 与 `.loctable` 对齐了 `com.apple.coreservices.uiagent`、`coreautha` 宿主识别，以及中英文确认 / 切换密码按钮与报错文案（包含英文 `"Sorry, you entered an invalid password."`）。
- **事件回调只读监听试验（macOS 27.3）：** 使用项目开发签名的临时诊断版完成了两轮（B1 / B2）非持续扫屏的事件回调只读监听试验。辅助功能权限就绪后，两轮试验均通过系统授权界面激活与窗口创建回调监测到 `zsh` 管理员授权弹窗出现：
  - B1：请求发出后 1.01 秒检测到授权界面激活，1.82 秒收到窗口创建事件，并于 1.82 秒在同进程公开提示中匹配 `zsh` 与脚本。
  - B2：请求发出后 0.99 秒检测到授权界面激活，1.61 秒收到窗口创建事件，并于 1.62 秒在同进程公开提示中匹配 `zsh` 与脚本。
  - 独立外部对照在请求前、弹窗出现后、撤回后分别核对，两次均匹配 `zsh`、管理员、脚本和允许访问，撤回后均未再匹配；两轮试验均未读取密码字段，也未提交授权。

### 已确认的锁屏状态保持要求

- 已在产品规则、主线程状态机与无硬件单元测试中明确约束并覆盖：锁屏本身不改变开启状态；已设截止时间在锁屏期间照常按墙钟生效；解锁后如实回显真实状态（未到期继续开启并更新剩余时长，已到期自动关闭，密码失效自动关闭）；锁屏保持不改变应用重启后默认关闭的行为。

### 未验证的能力与边界

以下能力与场景**尚未完成实机验证**，实机运行中遇到受阻或未覆盖弹窗一律保留由本人确认，绝不伪装为已批准：

- 在实机授予辅助功能权限后，向真实系统授权弹窗以及 `LocalAuthenticationRemoteService` 远程密码框（通行密钥 / Apple 密码内嵌弹层）自动填入密码与自动提交批准的可行性（包括 `AXSecureTextField` 的 `kAXValueAttribute` 可写性及系统安全机制对写值或 `CGEvent` 键盘事件的拦截表现）。
- 实机环境下 macOS 对 `UserNotificationCenter`、`AuthorizationPromptService` 等 TCC 软件权限许可弹窗执行 `AXPress` 自动点击的拦截表现与跨系统版本控件层级稳定性（受阻时保留由本人确认，绝不伪装为已批准）。
- 锁屏期间 macOS 是否会实际弹出管理员授权弹窗，以及锁屏状态下事件监测与自动处理能否生效。
- 真实管理员密码录入 / 更换 / 删除、物理锁屏解锁端到端表现、以及真实菜单栏常驻状态与右键一键关闭实测。
- 其他系统授权界面与第三方应用管理员弹窗的覆盖率。
- 其他 macOS 版本、英文及非中英文系统界面语言、触控 ID 优先界面切换、息屏 / 休眠唤醒竞态以及多授权弹窗并发处理。
