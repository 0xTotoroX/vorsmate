# Vorsmate 设计语言与设计系统

本文件沉淀 Vorsmate 在 macOS 14+（重点面向 macOS 26/27 Liquid Glass）上的完整视觉规范、交互协议与组件边界，作为所有菜单栏界面、独立浮层及后续新插件开发的唯一设计基准。

## 1. 核心哲学

- **一秒可读（1-Second Glance）**：打开菜单栏即可查看信息、工具和系统的状态。总览行左侧展示功能名与管理状态，右侧展示当前值或实测读数；错误、等待与运行中状态在收起时仍直接可见。
- **单信号克制（Single-Signal Restraint）**：一个交互区域只保留一种主强调信号。避免多层阴影、冗余装饰线条或全屏高亮按钮抢夺注意力；文字、符号与颜色同步表达状态，不单靠颜色区分信息。
- **有克制的温度（Warm Utility）**：以原生 macOS 控件、系统语义色与精准字体层级保持工具感，同时在高频专注时刻保留少量与真实状态联动的克制点睛表达。

## 2. 双场域架构与真·液态玻璃规范

Vorsmate 的界面分为**菜单栏控制面板**与**全屏/桌面浮层**两大场域，材质与分层规则严格分离：

### 2.1 菜单栏控制面板（`386pt` 固定宽度）

- **真·液态玻璃解锁要求**：macOS 26+ 必须通过链接当前本机 SDK 版本（如 `-platform_version macos 14.0 <SDK_VERSION>`）构建，才能解锁原生 `NSPopover` 与 `.glassEffect(...)` 的系统级液态玻璃；禁止使用旧版 SDK 回退（否则系统会退化为普通磨砂材质）。macOS 14/15 回退至 `.regularMaterial`，系统开启「减少透明度」时使用不透明系统背景色。
- **两层卡片上限（严禁三层嵌套）**：
  1. **背景层**：系统弹层自带液态玻璃底面，不再叠加普通模糊背景。
  2. **第一层前景容器 — `PanelSectionCard`**：总览页内按分类成组。圆角 `14pt`（`.continuous`），正常透明度下填充 `Color(nsColor: .controlBackgroundColor).opacity(0.55)`（减少透明度时为不透明 `controlBackgroundColor`），配 `1pt` `Color.primary.opacity(0.07)` 描边，在玻璃底面上建立清晰的物理景深。
  3. **第二层内嵌容器 — `PanelInlineCard`**：仅用于原地展开区域内部（`padding: 12` 或 `0`），圆角 `12pt`（`.continuous`），填充 `Color.primary.opacity(0.035)` 与 `1pt` `Color.primary.opacity(0.06)` 描边。禁止在 `PanelInlineCard` 内再套圆角卡片。
- **无轨道隐式滚动（Zero-Chrome Scrolling）**：`386pt` 菜单栏面板内所有滚动区（`PanelView`、`SourceList`、`QuickShutdownView`、`UnattendedAuthView`）一律隐藏可见滚动条轨道与滑块——SwiftUI 视图显式使用 `.scrollIndicators(.never)`，AppKit `SourceList` 使用锁定 `.overlay` 样式与 `0pt` 宽度的 `SilentScrollView` + `ZeroScroller`——彻底避免外接鼠标或系统开启「始终显示滚动条」时出现灰色槽位与双滚动条，同时完整保留触控板、鼠标滚轮、键盘上下与拖拽边缘自动滚动。
- **内嵌设备列表展开规则（`ChannelView`）**：`8` 项及以内完整展开、不截断也不嵌套滚动；超过 `8` 项时固定显示 `7.5` 行（`330pt`），以半行裁剪提示用户可继续滚动。

### 2.2 全屏与桌面屏幕空间

- **零文字纯图标工具条（Variant A2）**：全屏框选工具条（`SceneOverlayToolbarView`）与桌面贴图悬浮条采用 `.glassEffect(.regular, in: ...)`（减少透明度与旧系统回退 `.regularMaterial` + `1pt` 描边）。
- **聚焦选区框架**：选区外覆盖 `0.35` 透明度深色遮罩，选区本身保持 `0px` 直角像素锐利边缘、贴线 `12×12pt`（`2.5pt` 线宽）直角角标、白底强调色描边胶囊中点手柄与顶部外置尺寸胶囊，不引入遮挡视线的放大镜浮窗。
- **独立桌面贴图（`PinnedStickerWindow`）**：`NSPanel` 置顶悬浮（`isFloatingPanel = true`、`hidesOnDeactivate = false`），支持多贴图跨应用持久保留、左键拖动、四边/四角等比缩放、滚轮与双指捏合缩放（`0.25×–4.0×`）、`⌥+滚轮` 调透明度（`0.25–1.0`）、`⌘+`/`⌘-`/`0`/`⌘0` 缩放控制，以及右键 / `Control+左键` / 双击 / `Esc` 直接关闭当前贴图。

## 3. 模块组织与可扩展导航

- **顶部分类切换栏**：超过一个分类有启用模块时，在面板顶部图标下方展示纯图标三分类轨道（`PluginCategory`），悬停与辅助功能保留「信息 / 工具 / 系统」名称：
  - **信息（`.information`，`info.circle`）**：时间对照、天气、行情、待办。待办固定在末尾
  - **工具（`.tools`，`wrench.and.screwdriver`）**：截图、小米遥控器、窗口拖动、收藏封面、网盘
  - **系统（`.system`，`gearshape`）**：输入法、麦克风、播放设备、风扇、一键关机、无人值守授权
  - 轨道底色 `Color.primary.opacity(0.035)` 配 `Color.primary.opacity(0.08)` 描边（圆角 `11pt`），选中项填充 `Color.accentColor.opacity(0.11)` 配 `Color.accentColor.opacity(0.45)` `1.5pt` 描边（圆角 `8pt`），并使用 `Color.accentColor` 图标色；非当前分类存在活动状态或错误时，标签右上角显示 `5×5pt` 蓝/红微点提醒。
- **持久化模块排序与开关（`PluginOrderManagerView`）**：从「更多 → 功能模块…」进入，按分类展示全部可用模块，支持同分类内 `↑` / `↓` 调整可移动项目和启用开关，保存至 `Preferences.pluginOrder`（支持恢复默认）；正常与开发版中「Typeless 诊断与恢复」统一收口在「遥控器」详情页底部，仅 `--preview` 保留「更多」菜单直达入口。
- **二元导航约定**：
  - **原地展开（`⌄ / ⌃`）**：时间对照、输入法、麦克风、播放设备、风扇、截图、窗口拖动、收藏封面、网盘；同时只展开一项，切换分类自动收起。
  - **同宽推入详情（`› / ‹`）**：一键关机、无人值守授权、小米遥控器、待办、模块与顺序、Typeless 诊断；左上角统一使用 `‹ 上一级名称` 逐级返回。

## 4. 控件双轨规范（2A）

为兼顾系统原生质感与高频快捷操作密度，采用 `2A` 双轨控件标准：

| 控件类型 | 规范方案 | 典型示例 |
| --- | --- | --- |
| 模式切换、下拉菜单、开关、表单输入框 | **macOS 原生控件**（`.segmented`、`Menu`、`.pickerStyle(.menu)`、`.switch`、`.roundedBorder`） | 通道自动/锁定、目标语种、翻译引擎、无人值守密码菜单、遥控器方案/动作/按住选单 |
| 并列快捷预设与键帽录入触发器 | **无边框轻胶囊芯片**（`Capsule()`，选中 `Color.accentColor.opacity(0.14)`，未选 `Color.primary.opacity(0.06)`） | 无人值守时长预设（`15分 / 30分 / 1时 / 2时 / 自定`）、模型接口预设（`DeepSeek / OpenAI / Ollama`）、快捷键键帽 |

## 5. 图标与点睛图形标准

- **总览摘要与面板控件**：统一使用原生 SF Symbols（`18pt`、`24pt` 固定框宽），例如「一键关机」使用落日符号 `sunset` 保持品牌差异化（并与顶栏「系统」的 `gearshape` 区分）。
- **详情页点睛图形（每页最多 1 处，且必须与实时状态联动）**：
  - 「一键关机」详情头部保留彩色日落动画 `SunsetMark`（随执行进度动态沉落）。
  - 「小米遥控器」详情保留真实设备正面投影热区模型 `RemoteFace`（随实体按键/鼠标点击高亮）。
- **屏幕浮层自定义矢量图标（`ScreenshotVectorIcon`）**：全屏框选工具条与贴图悬浮条严禁混用 `Image(systemName:)`，所有图标统一绘制于 `20×20` 网格、`1.65pt` 圆头圆角描边（完成钩 `done` 为 `1.85pt`）。

## 6. 排版、色彩 Token 与间距规范

### 6.1 字体层级

- **面板顶栏**：顶部居中显示 `42×42pt` 单色展翼图标（`BrandIcon.panelMark`）与右侧 `16pt` 更多菜单图标（不显示应用名与开发版标签）
- **详情页标题**：`.title2.weight(.semibold)`
- **摘要行标题**：`14pt` `.semibold`
- **摘要行状态**：`12pt` 次要色
- **摘要行右侧数值 / 时间 / 温度 / 转速 / 倒计时**：`13pt` 强制 `.monospacedDigit()` 等宽数字，防止数值跳动引起布局抖动
- **内联说明与错误提示**：`PanelInlineNotice`（`.callout`，错误用 `.red`，提示用 `.secondary`）

### 6.2 色彩 Token

- **正文与次要文本**：系统语义色 `.primary` / `.secondary` / `.tertiary`
- **主强调色**：`Color.accentColor` 用于选中态、活动图标、主操作按钮；在全屏工具条（A2）中，**实心蓝圆背景仅保留给最终确认 `✓`（`done`）**，其余激活工具仅着色图标并在分割线上滑动 `5×5pt` 指示微点。
- **破坏性警示**：`Color.red` 用于错误提示、密码失效、未授权状态，以及「一键关机」在开启「强制退出应用」且存在待退出应用时的红色主按钮警示。
- **截图矢量标注调色板（`AnnotationColor.applePalette`）**：珊瑚红、活力橙、翡翠绿、电光蓝、靛蓝紫、深曜黑 6 色，配合 `thin (2pt) / medium (4pt) / thick (7pt)` 三档线宽。

### 6.3 布局与间距

- 面板固定宽度 `386pt`，外边距左右各 `20pt`（分组卡片 `PanelSectionCard` 水平外距 `16pt`，卡片内行水平内边距 `14pt`，垂直内边距 `12pt`）。
- 全面板采用无轨道隐式滚动（不预留滚动条宽度）；设备优先级列表 `8` 项以内全展，超过 `8` 项时以 `7.5` 行（`330pt`）露半行暗示滚动。
- 未展开或未触发态不留禁用占位灰字（例如时间对照未选定自定义时刻时不显示置灰「现在」按钮）。

## 7. 交互保护、保守默认与可插拔铁律

- **输入保护（`protectInteraction`）**：录入快捷键、编辑接口地址/密钥、输入管理员密码、聚焦关机应用搜索框或编辑时间日期时，主动挂起弹层失焦自动收起，离开或收起时立即复位 `false`。
- **高风险保守默认**：
  - 无人值守授权默认选中「按时长」（`30 分钟`），避免默认无限期授权；「已弹出的请求和「隐私与安全」请求由本人确认」边界提示在开启与关闭态始终可见，且开启前已存在的弹窗与系统设置「隐私与安全」弹窗均保留由本人确认、不自动填密。
  - 所有配置变更采用原子保存；保存失败或取消保存图片时保留当前现场、标注与输入，不静默丢失用户进度。
- **可插拔零残留（`VorsmatePlugin`）**：所有模块经 `PluginHost` 统一管理生命周期；停用插件即刻注销全局热键、停止后台子进程或轮询，并销毁全部叠层与悬浮贴图。
