# 工具模块

从「更多 → 功能模块…」开启「收藏封面」或「网盘」。开启后可在「工具」页展开操作。

## 收藏封面

打开 Eagle 并载入目标素材库，在「音乐」中播放或选中歌曲，然后点「收藏当前封面」。首次需要允许 Vorsmate 自动化控制「音乐」。封面按原始字节导入到 Eagle 的「音乐封面」，并补充歌曲、歌手和专辑信息。同名或同歌手同专辑的封面会跳过。

## 网盘

现有 OpenList 按需挂载用户可将本机连接器的 `runner.py` 和 `mounts.py` 放在 `~/Library/Application Support/OpenList-OnDemand/Connector/`，并保留已配置的 `/usr/bin/python3`、rclone、挂载用 LaunchAgent 模板与本机连接。模块提供「打开配置目录」入口。连接器、账号信息和挂载配置由使用者在本机管理。

Vorsmate 直接调用连接器的 `status`、`start`、`stop` 和 `gui`。状态返回各挂载的开启或关闭及专用连接状态。开启成功后打开 Finder，网页入口仅打开连接器返回的本机登录地址。关闭继续使用连接器原有的挂载、网页任务、服务与待上传检查。菜单栏收起时，已经发起的操作继续完成。
