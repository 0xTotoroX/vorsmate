# 小米遥控器

VorsmateRemote 是独立的 macOS 插件。将配套的 VorsmateRemote.app 和 Vorsmate.app 放在同一目录，在宿主「更多 → 功能模块」开启「遥控器」。插件默认关闭。点击菜单栏面板的「遥控器」行，切换单击、双击或长按即可查看当前映射。收起面板后映射继续工作，停用插件或退出宿主会释放设备。

## 按键与配置迁移

支持小米蓝牙遥控器 2 Pro（RC003）的 12 个普通实体键、每键的单击 / 双击 / 长按，以及独立的语音键。点击总览顶部的遥控器图片或名称即可进入模型，点机身上的实体键进行设置。列表也能直接打开对应的键。在详情页顶部也可以用键盘选择实体键。「重新录入」在面板里接收一次快捷键，保存后显示插件回读的结果。每个手势可以录入快捷键、设置媒体动作、打开应用或选择无动作。实际配置保存在当前用户的 Application Support/VorsmateRemote/buttons.json。预览编辑只在内存生效。

未导入配置时，确定键单击默认为左 Control＋左 Option＋V，可直接重新录入。旧版 Typeless 预设在界面中显示为这组快捷键，保留原有的运行检查。迁移本机 SayAll 2.0.8 当前选中的 RC003 档案：

```sh
python3 scripts/import-remote.py
```

工具只读旧配置，把所选设备的覆盖项、快捷键、应用目标、禁用动作、快速连按、手势时限和语音 Fn 设置写到插件自己的文件。确定键单击保留已验收的 Typeless 动作。已有不同目标文件或遇到不支持的配置会停止；可用 `--source` 和 `--output` 指定备份及新的目标文件。导入后重新启用插件。个人设备标识、用户配置与诊断不随源码分发。

配置了双击的键在松开后等双击窗口结束，第二次点击在窗口内开始则只执行双击。默认长按只在达到阈值时执行一次；松开不会再发单击。语音键的 Fn 按下和释放由设备级映射交给系统。

手势按 HID 报告的时间戳判定。超时动作额外留出 20 毫秒供系统交付已到达的报告，原有双击和长按时限不变。

## 应用方案与按住连发

进入「键位方案 → 添加应用方案」选择应用。默认方案对所有应用生效，应用专属方案只覆盖改过的手势和按住方式。选「沿用默认动作」恢复继承，选「无动作」只在该应用禁用。移除应用方案后恢复默认。菜单中选择的是正在编辑的方案；实际派发跟随 macOS 的前台应用。

在普通键详情的「按住时」可选执行一次、连发单击动作或连发长按动作。到该配置的长按时间时执行第一次，之后每 120 毫秒执行一次，松手停止。选择连发单击时，这个键的持续按住执行单击动作，短按和双击仍按原设置判定。如果应用方案把连发的目标动作设为「无动作」，按住和松开均不会执行其他动作。切换前台应用、断连、编辑配置或停用会取消待判和连发，按住的键需先松手。语音键仍由固件按住收音。

首次保存应用方案或连发时，会把当前键位完整写入同目录的 buttons-v2.json。新版随后使用这份配置。原有 buttons.json 保留给旧插件，后续两个版本的编辑分别保存。导入与面板保存共用同一把写入锁，同时编辑时会提示配置已变更。导入工具支持所选设备的重复单击和重复长按，重复间隔采用 Vorsmate 的设置。

## 接入方式

- 配对后 macOS 将 RC003 枚举为低功耗蓝牙 HID 键盘。插件通过 IOKit 匹配蓝牙传输、厂商 0x2717、产品 0x32b8 和键盘用途。普通按键来自报告 1，每帧最多三个小端 16 位键值。
- 插件以共享方式读取这只设备的原始输入，只在它的键盘服务上临时屏蔽已配置的原生键。Fn 配置将遥控器 F5 映射到系统 Fn。写入后回读完整映射；停用时按所属标记撤回。相同型号设备超过一只、现有映射冲突或 SayAll 正在接管时会等待。宿主管道断开触发清理；插件被强制终止后的残留由下次启动按同一启动会话、服务身份恢复。
- 需要 Typeless 接收遥控器的原生键时，可以把确定键的单击设为单独的 F18，双击和长按选「无动作」，按住时选「执行一次」。在 Typeless「设置 → 快捷键 → 语音输入」点「添加另一个」，短按遥控器确定键录入 F18。已有的实体键盘组合键可以继续使用。F13–F20 的单键可由 RC003 的设备映射发出。其他组合键和配置了多种手势的按键沿用原有派发方式。
- 普通快捷键和 Typeless 均使用系统键盘事件。录入支持左、右 Control、Option、Command 和 Shift，可单用或组合其他键。确定键的预设依次按下左 Control、左 Option、V，再释放，保留原来的双击与长按。若某个实体键只配置了一个单独的修饰键，设备级映射会保留真实的按住时长。旧配置中没有记录左右侧的通用组合按左侧发送。快捷键派发需要辅助功能权限。
- 项目代码与原创遥控器模型采用 MIT，构建时随附 LICENSE。可编辑的模型是 [RC003.blend](../Resources/Remote/RC003.blend)。

## 遥控器收音

开启遥控器插件并允许蓝牙访问。在 Vorsmate 原有「麦克风」列表中选择或拖动「MiRemoteV 2ch」，或让自动模式按已有顺序选择。Typeless 使用系统默认麦克风或明确选中该设备。短按确定键开始听写，按住右上角语音键说话，松开语音键，然后再短按确定键结束。其他普通键可以发送听写快捷键，当前 RC003 适配只能由实体语音键启动遥控器收音。每次持续时间受遥控器固件限制。

插件通过 macOS CoreBluetooth 连接已配对且在线的 RC003，订阅 ATVV 控制和音频通知，确认 16 kHz 模式后独立解码 IMA ADPCM。PCM 只写入已安装的「MiRemoteV 2ch」回环设备，系统扬声器和默认播放设备保持原设置。遥控器与回环均就绪时才参与自动选择；断开后按原顺序回退，重连后恢复。停用时归还输入管理权给系统和其他音源。端点缺失时，语音键页面会显示所需设备，按键映射可继续使用。插件不附带第三方驱动，也不调用 SayAll 或旧的虚拟键盘桥。[公开设备协议说明](https://github.com/HD838A/remote-mic-app/blob/v2.0.8/TECHNICAL.md) · [RC003 实景语音时限](https://github.com/HD838A/remote-mic-app/blob/v2.0.8/Testing/RC003VoiceExtensionPreview.md)

语音键优先使用遥控器的蓝牙控制通知打开麦克风。设备的实体按下到达后，若 120 毫秒内未收到启动通知，插件会尝试直接向同一只遥控器打开麦克风。松开后给蓝牙末包保留 350 毫秒。3 秒未收到首包或已收音时 1 秒没有新包，会在下一次状态检查中重连语音服务。静音的有效音频包也维持会话。下一次按住赶上前一段语音收尾时，先暂存音频包，等队列确认停止再按顺序写入。

## 开发验证

`bash scripts/build.sh` 生成两个独立应用。临时签名构建核对配套代码签名哈希，正式签名构建校验同一 Apple 团队。主程序安装包可以独立分发。需要和正在使用的构建共存时，可设置 VORSMATE_DIST_DIR 指定独立产物目录。开发预览使用 --preview --preview-popover --show，打开带虚构遥控器配置的原生菜单栏面板。

直接打开插件显示隔离预览。运行 `dist/VorsmateRemote.app/Contents/MacOS/VorsmateRemote --verify` 进入单独的真机验收。用空白输入框检查确定键单击开始 / 结束、双击及长按；验收输出记录按键次数、换行计数以及语音段的采样数和峰值，不保存音频或输入内容。退出后回读设备级 UserKeyMapping 确认恢复。
