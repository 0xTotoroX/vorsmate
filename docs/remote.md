# 小米遥控器

VorsmateRemote 是单独的 macOS 插件应用。将配套的 VorsmateRemote.app 和 Vorsmate.app 放在同一目录，打开主程序，在「更多 → 功能模块」开启「遥控器」。首次安装和旧配置升级均默认关闭。关闭主面板或键位窗口后映射继续工作；停用插件或退出宿主会释放设备。

当前支持小米蓝牙遥控器 2 Pro（RC003）的确定键。Typeless 中的听写切换快捷键应为左 Control + 左 Option + V。短按后松开一次开始，再短按一次结束。长时间按住只在松开时提交一次。其他键保留各自在系统中的行为。键位窗口使用项目原创的哑光铝 Blender 正面图。

## 本机依赖

- macOS 14 或更高，已配对并连接一只 RC003，Typeless 正在运行。插件需要输入监控权限。SayAll 运行时插件暂停接管。
- 当前听写输出使用已安装的本机虚拟键盘桥和兼容的 Karabiner-DriverKit-VirtualHIDDevice。本次验收使用 8.5.0 的驱动和既有的本地桥。插件只向指定用户可访问、由 root 服务接受连接的 Unix 套接字发送一个固定请求。桥不可用时显示状态；发送回执丢失时不自动重试。
- 本项目的插件代码与模型图采用仓库的 MIT 许可证。构建产物随附 LICENSE。桥和第三方驱动单独提供，插件包不含其程序或源码。

## 开发验证

运行 `bash scripts/build.sh` 在 dist 下构建两个配套应用。开发临时签名的宿主核对构建时记录的插件签名哈希，正式签名构建要求同一 Apple 团队。主程序安装包可以独立分发。

直接打开插件仅显示模型预览。显式运行 `dist/VorsmateRemote.app/Contents/MacOS/VorsmateRemote --verify` 可单独做实机验收。点验收输入框，短按两次，中间观察 Typeless 开始与停止。核对两次发送以及空白输入框零换行。退出验收窗口后回读设备的 UserKeyMapping，确认恢复。计数器只计数，验收日志不记录听写文本。多只同型设备、已有确定键映射或其他会话占用时等待处理。

设备级临时映射只给已识别的蓝牙键盘服务添加 Return 屏蔽项，读取回验后才派发快捷键。停用时按插件标记只移除自有条目。其他程序后来写入的同键映射也会保留。宿主异常退出依靠控制管道断开清理；插件被强制终止后的残留条目在下次启动时按同一系统启动会话与服务身份恢复。拔掉设备会使该服务的临时映射失效。
