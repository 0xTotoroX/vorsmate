# 验证范围

当前为预览版本。本地测试、真实硬件观察和公开二进制分发分别验收；通过其中一项不代表其他项已经完成。

## 自动检查

CI 在 macOS 上执行 Swift 格式检查、`swift test` 与 `scripts/build.sh`，验证临时签名的应用和助手、检查随包许可。测试使用替身，不切换运行机器的输入法或音频设备，也不调整真实风扇。

截至 2026-11-13，本地 100 项规则 / 控制器测试与 9 项 AppKit 事件测试覆盖：

- 独立优先级、手动锁定、离线回退与重连恢复。
- 三通道排序松手一次保存、自动模式采用新顺序、配置往返、无效移动不写入及保存失败回滚。
- 三点即时起拖、点击与拖动分离、Escape / 列表外松手 / 关闭取消、外部配置变化取消过时手势、普通回读不中断和长列表边缘滚动；控制器先更新时拒绝旧下标、动画中的离线移除命中保护、窗口关闭但内容保留时取消。
- 无线接收器连接帧校验 / 分包、两种协议、同长度非状态包、静音字段无关、去抖与过期、发射器连接后的优先级和锁定回退。
- 配置往返、损坏保护、版本检查和并发保存冲突。
- 设备变化通知、冷却与单次退避重试、无通知自动恢复、持续异常提示、成功后反复切走的限频、关闭 / 退出取消复查、迟到结果和只读刷新。
- 均衡 / 强冷的持续确认、分段曲线、温度平滑、趋势提前量及冷却释放。
- 固定转速范围、有效温度、系统压力、写前恢复责任、外部接管和租约失效。
- 当地 / 美西时间、跨日跨年、非整点与反向时差、两地各自的夏令时和 23 / 25 小时滑杆。

v0.1.0 发行准备中，格式检查、81 项测试和 Universal 构建已在本地通过，随包许可与源文件逐一核对。隔离预览检查了当地日期编辑、跨日与回到现在、设备模式和风扇档位，README 截图使用演示数据。该次发行准备没有替换已安装应用或重测真实调速。

2026-11-12 的恢复逻辑修复通过了格式检查、86 项测试和本机 arm64 签名构建。以真实控制器和界面组件搭配模拟驱动，检查了“恢复中”无红字、持续异常提示、正常回读后恢复锁定并清除提示；无通知恢复和取消复查另外使用真实定时任务验证。没有人为干扰真实输入法制造争抢；最初触发异常的系统事件尚未复现，不能把模拟验证视为跨应用或密码输入框验收。

发行包包含 arm64 与 x86_64 的应用和助手，使用同一 Apple 开发签名，提供拖放安装 DMG 与 SHA-256 校验文件。镜像完整性、挂载内容与签名分别检查；这不是 Developer ID 或 Apple 公证，也不代表在其他用户电脑上无提示安装。

## 已完成的实机观察

核验环境：M4 Mac mini（Mac16,10）、macOS 27.3、Xcode 27.2。该环境不代表所有目标系统和机型。

| 范围 | 已观察结果 |
| --- | --- |
| 原生面板 | 紧凑总览、按需展开、长列表、深色预览；鼠标离开自动收起，后台管理继续 |
| 单列表拖动 | 三个通道的原生隔离预览均完成直接鼠标拖排；点击切换并锁定、排序不触发锁定、收起重开保持顺序、长列表滚动后拖排及列表外松手取消已观察。边缘停留自动滚动另由 AppKit 事件测试覆盖 |
| 时间 | 双时钟、日期换算、关闭面板回到当前时间 |
| 无线麦连接 | DJI Mic Mini 2 的原生 USB 状态读取；发射器关闭且接收器仍在线时自动回退，重新连接后恢复优先选择；暂停说话期间连续 25 秒保持无线麦，列表正确显示等待发射器；锁定未连接接收器时先使用备用 |
| 风扇助手 | 系统授权、签名身份校验、XPC 往返、安全更新与停用 |
| 固定转速 | 2500 / 3000 RPM 分别保持约 30 秒，实际转速跟随；有效核心热点超过 90°C 时仍可选择和保持 |
| 新均衡 | 自然负载下最高约 2208 RPM，实测加速、缓降、冷却后归还系统并保留档位 |
| 新强冷 | 自然负载下最高约 3665 RPM，实测接管、缓降与显式归还系统 |
| 恢复 | 正常退出归还系统；既有租约实现曾实测失联约 12 秒后归还 |

对应自然负载下，系统自动约为 1000 RPM。各段功耗并不固定，不能据此推算降温幅度、噪声分贝或性能收益；强冷完整自然冷却归还目前仅由模拟轨迹覆盖。

## 尚未验收

- 真实音频设备反复插拔与蓝牙重连、输入法跨应用及密码输入框边界。
- 无线接收器的旧版协议仅由合成状态帧覆盖；其他固件、同序列号多接收器和长期睡眠恢复尚未实机验收。当前规则与限制见[无线麦说明](wireless-microphones.md)。
- 实机静音按键未操作；已验证暂停说话不误切，静音 / 音量等无关字段不改变连接判断由协议测试覆盖。
- 全部目标 macOS 版本、其他 Mac 型号、整机重启、睡眠唤醒和长期冷热循环。
- 安装位置固定后的登录启动、进程崩溃、实际严重 / 临界温度压力和传感器故障；异常条件主要由替身测试覆盖。
- Developer ID 分发、Apple 公证、Intel 实机、其他用户电脑的首次安装与自动更新。

源码公开不等同于经过公证的安装包发布。问题报告请提供型号、系统版本、模式与复现步骤；去掉设备 UID、个人路径和签名信息后再附诊断。完整策略见[风扇控制](fan-control.md)。
