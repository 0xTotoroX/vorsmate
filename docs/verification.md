# 验证范围

本地测试、真实硬件观察和公开二进制分发分别验收；通过其中一项不代表其他项已经完成。

早期应用更新开发版另通过 107 项核心 / 控制器及 12 项界面测试。隔离应用验证了损坏签名被拒绝、有效载荷验签 / 解包 / 替换 / 重启及包外配置保留；新的紧凑交互窗口也完成隔离升级到更高版本。真实应用配置与风扇助手进程未被隔离测试改动。此验证不等于从 GitHub 发布版直接升级的完整验收；v0.3.0 起安装包包含更新器；当前 Release 仅提供 DMG，签名更新清单单独维护在固定 updates 分支。协议与发布步骤见[应用更新](updates.md)。

## RC003 确定键

2026-11-18，SayAll 退出后，使用独立插件和已有虚拟键盘桥在一只小米蓝牙遥控器 2 Pro 上实测。第一次短按打开 Typeless 录音条，第二次结束，验收输入框没有换行，两个操作各收到一次提交回执。关闭验收进程后回读确认设备映射恢复。在原生宿主预览中验证了从功能模块启用插件、打开键位窗口和停用后子进程退出。新机器安装驱动、睡眠唤醒和公开签名分发仍需另验。

全键迁移后，独立核对本机所选 RC003 的 36 个普通键手势、两个快速连按开关、手势阈值与语音 Fn；系统回读了该设备的 13 条映射。原生窗口展示了导入的确定键三种动作。模拟报告检验去重、所有普通键的互斥手势、错误报告和注销状态；这些验证不代表已在每个前台应用逐键实按。

同日，在 SayAll 退出、系统输入为 MiRemoteV 2ch 的环境，独立验收版直接发送带左右修饰键的键盘事件，完全绕过旧键盘桥。用户实测确定键能启停 Typeless，按住遥控器语音键说出测试短句后，Typeless 正确识别。插件收到两段非空 16 kHz 音频。最终版将同一路径设为默认并删除键盘桥客户端。在原生预览录入框分别送入右 Control＋右 Option＋左 Command＋K 和单独的右 Command，回读显示侧别正确。输入排序回退有自动测试覆盖，其他快捷键未逐个用 Typeless 实按。

应用方案与连发的回归覆盖了禁用目标动作、松开无尾击、发送权限缺失时保留确定键屏蔽，以及多份编辑同时从旧配置升级只接受一次保存。原生宿主预览中从「功能模块」启用插件，在确定键详情保存并回读了「连发单击动作」。只读核对了一只已配对 RC003 的 HID 身份与已连接蓝牙端点相符。跨应用按住实键、睡眠唤醒后重新收音仍需真机验收。

2026-11-19，在 macOS 27.3 和 Typeless 2.12.0 上复现两次独立短按都送出左 Control＋左 Option＋V、听写却没有稳定启停。按发送时刻标记事件并分开组合键的按下和释放后，用户实按确认确定键能启动和结束听写，空白文稿保持为空。系统回读确认原生回车仍被设备级映射屏蔽。已卸载 SayAll 和旧虚拟键盘桥，仍使用 macOS 快捷键派发。

2026-11-20，登录后的旧进程一直未接管已连接的 RC003。新建 HID 查询客户端可看到唯一匹配服务，修复后在同一登录会话重载本地签名构建，系统回读 13 条设备映射及确定键的回车屏蔽。原生预览中点模型上的 TV 键，标题和蓝框移至 TV 键。用户实按确认语音键进入收音、模型显示按键高亮，确定键可启动和结束 Typeless 听写。登录后自动恢复仍需下一次正式登录验证。

2026-11-21，同一输入框内实体键盘能启动 Typeless，遥控器发出的同组快捷键经过事件链末端却未启动。重开 Typeless 恢复启动，旧版插件仍不能稳定结束。复用同一个快捷键事件源并错开组合键松开后，用户实测短按启停，空白文稿保持为空。系统共记录 11 次短按各派发一组完整组合键，未发回车或数字小键盘 5，设备级回车屏蔽仍有效。既有快捷键、遥控器键位和麦克风排序均核对一致。

2026-11-22，旧运行版重登后复现 Typeless 未采纳已完整派发的快捷键，微信唤醒后不出字。隔离测试覆盖 HID 手势边界、首包超时和断流。模拟音频队列验证上一段异步停止时保留下一段首包、确认停止后顺序写入，以及断连清理。

同日，在开机后已复现故障的会话中换入新版遥控器组件，保留原 Typeless 进程。实物报告的时间戳可读，6 次独立短按各发出一组启动快捷键且到达前台，听写仍未启动。另有一次相隔约 120 毫秒的双击按既有配置发出数字小键盘 5。未发回车，设备级回车屏蔽仍生效。语音键两次按住约 4 秒和 2 秒，系统输入为遥控器的虚拟麦克风，探针未测到可用电平，微信输入法未出字。快捷键、遥控器键位和麦克风配置核对一致。新版验证了设备计时，听写和微信收音均未通过端到端验收。

## Typeless 诊断与恢复

从原生菜单栏「更多 → Typeless 诊断与恢复」分别模拟实体键盘快捷键失灵与遥控器未接管。前者显示已停用的监听与仍按下的修饰键，后者显示遥控器已连接、Vorsmate 未接管。确认前可取消，保存失败或退出请求被拒绝时停止。模拟正常退出后重新打开并刷新状态，模拟超时后停止重新打开。隔离目录中另核对了诊断 JSON 的范围与访问权限。

本机只读检查确认 Typeless 正在监听、RC003 已连接且有 Vorsmate 映射，旧桥接服务和系统扩展未加载。验收前后对比了 Typeless 快捷键及麦克风选择、Vorsmate 麦克风顺序与锁定、遥控器映射。实际快捷键故障未在本轮复现，运行中的 Typeless 保持原进程。
