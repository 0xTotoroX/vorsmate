# 无线麦克风就绪判断

支持 DJI Mic Mini 系列 USB 接收器（`2ca3:4011`）的发射器连接检测。接收器在线与发射器连接分别判断：

- 只有接收器时跳过该项，按原优先级使用下一个可用麦克风。
- 至少一只发射器稳定连接后重新参与优先级选择；全部断开后回退。
- 手动锁定保留；锁定设备未就绪时临时回退，连接后恢复。
- 静音、音量为零、说话停顿不改变就绪状态，不录音或申请麦克风采集权限。

连接至少由两个有效状态包确认，时间跨度至少 0.3 秒；全部断开至少确认 0.8 秒，减少瞬时无线抖动造成的切换。超过 3 秒没有有效连接状态即视为未知，使用其他可用项并继续检查。实际切换还受设备推送频率和现有切换限频影响。没有备用设备时不会凭空产生新的输入设备。

实现通过 macOS IOKit 只打开厂商接口 6、读取 Bulk IN `0x86`，不分离 HID / 音频驱动、不写控制命令、不更改接收器设置。独立实现参考 [DJI Mic Control 的协议说明](https://github.com/ShadowBitBasher/DJI-Mic-Control/blob/main/PROTOCOL.md)，对帧头、校验和、状态记录形状和版本做校验；v2 使用连接掩码，v1 使用连接槽标志。

状态按 USB 序列号与 CoreAudio UID 对应。无法区分的同序列号多接收器、接口被占用、未知固件或读取失败时不自动提升该接收器；展开列表显示未知并继续重试。普通有线、蓝牙及其他音频设备保持既有选择规则。第三方应用若固定了自己的录音设备，不一定跟随 macOS 默认输入变化。

当前实机范围与未验收项见[验证范围](verification.md)。USB 原始帧可能包含设备身份，只留在本地忽略目录，不加入公开日志或仓库。
